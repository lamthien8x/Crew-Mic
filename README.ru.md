## Почему Crew Mic?

Записать подкаст с тремя гостями, вести стрим с соведущим или подключиться к гибридной встрече из шумной комнаты — обычно для этого нужны комплекты радиомикрофонов стоимостью в десятки тысяч рублей.

**Но микрофоны у вас уже есть — это ваши телефоны.**

Crew Mic подключает **несколько смартфонов** к одному компьютеру через локальную сеть Wi-Fi. Каждый телефон становится отдельным микрофонным каналом с **ИИ-шумоподавлением**, **автоматической синхронизацией микрофонов** и **защитой от перегруза**. Итоговый микс выводится как **виртуальный микрофон**, который можно выбрать в любой программе.

> 🎙️ Без кабелей. Без приёмников. Без дополнительного оборудования. Установите приложение, откройте его на телефонах — и говорите.

## ✨ Ключевые возможности

| | Возможность | Что это даёт |
|---|---|---|
| 📱 | **Несколько телефонов одновременно** | Подключайте сразу несколько Android-устройств и iPhone. Каждое получает собственный канал. |
| ⚡ | **Wi-Fi-аудио с низкой задержкой** | Несжатый звук 48 кГц по UDP кадрами по 10 мс. Типичная общая задержка — **40–100 мс**. |
| 🔇 | **ИИ-шумоподавление, 4 уровня** | Нейросеть RNNoise (Выкл / Слабое / Среднее / Сильное с шумовым гейтом) убирает шум вентиляторов, кондиционера и улицы. Переключение уровней без щелчков. |
| 🎯 | **Синхронизация нескольких источников** | Выравнивает все телефоны по реальному моменту записи с точностью ≤ 5 мс (p95). Это убирает «пустой», «туннельный» звук, возникающий при рассинхроне двух микрофонов. |
| 🛡️ | **Мастер-лимитер** | Look-ahead-лимитер (≤ 1 мс, потолок −1 dBFS) не даёт звуку искажаться, когда все смеются одновременно. |
| 🎛️ | **Микшерный пульт на компьютере** | Усиление, mute, сдвиг по времени (±100 мс) и VU-индикаторы 30 Гц для каждого канала, плюс мастер-шина. |
| 🎧 | **Контроль в наушниках** | Слушайте живой микс через отдельный выход: AirPods, USB-ЦАП или разъём 3,5 мм. |
| 🔌 | **Работает с любыми приложениями** | Вывод на виртуальный микрофон (BlackHole в macOS, VB-CABLE в Windows) для Zoom, OBS, Discord, Meet, Teams и DAW. |
| 🔍 | **Автоматическое обнаружение** | Телефоны находят компьютер через mDNS/Bonjour. Каждое устройство подключается только после вашего подтверждения. |
| 🔒 | **Всё остаётся в вашей сети** | Звук идёт напрямую с телефона на компьютер по локальной сети. Ничего не загружается в облако. |

## ⚙️ Режимы задержки

| Режим | Ожидаемая общая задержка | Лучше всего для |
|---|---|---|
| **Низкая** | 40–60 мс | Живых интервью и разговоров в реальном времени при сильном Wi-Fi 5 ГГц |
| **Сбалансированный** *(по умолчанию)* | 60–100 мс | Большинства пользователей с обычным домашним или офисным Wi-Fi |
| **Стабильный** | 100–180 мс | Слабого сигнала, больших расстояний или перегруженных сетей |

## 🧠 Как это работает

```text
 📱 Телефон 1 (Android) ─┐
 📱 Телефон 2 (iPhone)  ─┼── Wi-Fi LAN · 48 кГц PCM · UDP ──►  💻 Crew Mic Desktop
 📱 Телефон N (...)     ─┘                                      │
                                                                ├─ Адаптивный джиттер-буфер
                                                                ├─ Компенсация дрейфа часов
                                                                ├─ ИИ-шумоподавление RNNoise
                                                                ├─ Синхронизация источников
                                                                └─ Look-ahead-лимитер
                                                                       │
                                         ┌─────────────────────────────┴───────────────┐
                                         ▼                                             ▼
                          🎙️ Виртуальный микрофон (BlackHole / VB-CABLE)    🎧 Контрольные наушники
                                         │
                                         ▼
                           Zoom · OBS · Discord · Meet · Teams
```

Десктопный движок написан на **Rust** (Tauri v2) для обработки звука в реальном времени: lock-free-микширование без выделения памяти в аудиопотоке. Мобильные приложения используют нативные аудио-API (Android `AudioRecord`, iOS `AVAudioEngine`) для записи с минимальной задержкой.

## ❓ Частые вопросы

<details>
<summary><b>Можно ли использовать телефон как микрофон для ПК или Mac?</b></summary>

Да. Установите Crew Mic на телефон и компьютер, подключите их к одной сети Wi-Fi — и телефон станет беспроводным микрофоном в любой программе на компьютере.
</details>

<details>
<summary><b>Сколько телефонов можно подключить одновременно?</b></summary>

Crew Mic рассчитан на несколько микрофонов одновременно. Для подкаста или дискуссии обычно используют 2–4 телефона, у каждого свой канал с усилением, mute и шумоподавлением.
</details>

<details>
<summary><b>Работает ли это с Zoom, OBS, Discord и Google Meet?</b></summary>

Да. Crew Mic выводит микс на виртуальное аудиоустройство (BlackHole или VB-CABLE). Просто выберите его как микрофон в приложении.
</details>

<details>
<summary><b>Нужен ли интернет?</b></summary>

Нет. Звук передаётся только по локальной сети (Wi-Fi LAN); телефонам и компьютеру достаточно быть в одной сети.
</details>

<details>
<summary><b>Можно ли совмещать Android и iPhone?</b></summary>

Да. Устройства Android и iOS подключаются к одной сессии и синхронизируются автоматически.
</details>

<details>
<summary><b>Почему с двумя микрофонами звук становится «пустым»?</b></summary>

Это эффект гребенчатого фильтра из-за рассинхрона микрофонов. Включите **Синхронизацию источников** в Crew Mic, чтобы выровнять все каналы с точностью до нескольких миллисекунд.
</details>
